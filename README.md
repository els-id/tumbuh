# Tumbuh

Aplikasi latihan ujian **offline** untuk siswa SMA/SMK di laptop **Windows 10/11 (64-bit)**. Gratis, tanpa akun.

**Halaman unduh resmi: https://els.id/tumbuh**

File aplikasi ada di bagian [Releases](https://github.com/els-id/tumbuh/releases). Di bagian *Assets*, pilih `Tumbuh-Setup-….exe`. Jangan unduh *Source code (zip)* atau *Source code (tar.gz)*: itu dibuat otomatis oleh GitHub dan bukan aplikasinya.

Repositori ini hanya tempat unduhan resmi dan tidak berisi kode sumber. Tumbuh tidak pernah meminta bayaran, kata sandi, atau kode OTP, dan tidak ada versi HP (.apk).
